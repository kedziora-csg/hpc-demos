# `launch_cf` Tutorial Examples

These examples demonstrate how to use `launch_cf` on Derecho and show how processes are run and placed on nodes.

## Example 1: One Process Per Core with Multiple Nodes

The directory `derecho-640procs` has a command file, `cmdfile`, with 640 commands that each run `hello_omp.exe` with a specified run number. This was generated by using

```
gen_cmdfile.sh --nsteps 640 --exe "../hello_omp.exe" \
                --output "derecho-640procs/cmdfile" \
                --ppn 128 --nthreads 1
```
